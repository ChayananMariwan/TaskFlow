# 🚀 TaskFlow Dashboard

A modern task management dashboard built with HTML, CSS, JavaScript, and Supabase.

Live Demo:
https://taskflow-dashboard-neon.vercel.app/

---

## Features

- User Authentication (Login / Register)
- Create, Edit, Delete Tasks
- Task Priority (High / Medium / Low)
- Task Categories
- Custom Tags
- Due Date
- Search Tasks
- Dashboard Statistics
- Task Progress Chart
- Dark Mode
- Drag & Drop Kanban Board
- Database with Supabase

---

## Tech Stack

### Frontend

- HTML
- CSS
- JavaScript

### Backend / Database

- Supabase

### Deployment

- Vercel

## Installation

Clone repository

```bash
git clone https://github.com/ChayananMariwan/TaskFlow.git
cd TaskFlow
```

Configure Supabase credentials

```javascript
const SUPABASE_URL = "YOUR_SUPABASE_URL";
const SUPABASE_ANON_KEY = "YOUR_SUPABASE_ANON_KEY";
```
